# Loghi delle autorità israeliane — SOLO PER TEST LOCALE

ATTENZIONE: questi loghi appartengono alle rispettive autorità dello Stato di Israele.
NON devono essere pubblicati sul sito senza autorizzazione scritta delle autorità.
Usarli può far pensare a un'approvazione o a una partnership che non esiste.

Vengono inseriti nell'HTML (come data URI) SOLO se la build è lanciata con SHOW_TEST_LOGOS=1
(vedi src/config/flags.ts). Questa cartella è fuori da public/, quindi non finisce mai in dist/ di default.
