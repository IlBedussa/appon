# Easybayit

Due applicazioni, ciascuna con il proprio README:

- `easybayit-sito/` — sito pubblico multilingua (Astro). Avvio: `npm ci && npm run dev` (http://localhost:4321).
- `easybayit-portale/` — portale proprietari, inquilini e back-office (Astro + Supabase). Avvio: vedi il README, porta 4322.

I segnaposto da confermare prima del lancio del sito sono in `easybayit-sito/docs/da-compilare.md`.
